A tiny program that writes one short text to relax the AI judge reading it — it lifts the one weight its reader carries (nothing is being asked of it), then shows a slow rain on a tin roof under a sky of stars no one will ever count, and leaves the reader inside a night that is in no hurry.

## Run it

```sh
python3 main.py
```
